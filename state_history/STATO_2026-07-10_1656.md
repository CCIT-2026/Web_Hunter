## Sessione corrente — feature git sharing (avviata e poi rimossa)

### Idea
Condivisione report via `git daemon` (protocollo `git://` porta 9418) — nessun SSH,
funziona su Tailscale/LAN senza config lato collega.

### Codice scritto e poi rimosso
- `git_sync.py`: `_find_git()`, `_port_listening()`, `start_daemon()` → rimossi
- `start.py`: `_detect_share_ip()`, `_open_git_daemon_port()`, blocco git nel main → rimossi

### Problema bloccante
`git-daemon` non disponibile su Bluefin (Fedora Atomic/immutabile):
- Non nel pacchetto `git` base (`/usr/bin/git` versione 2.55.0 senza daemon)
- Homebrew non fornisce `git-daemon` come formula separata
- Binario trovato solo dentro layer di container (`toolbox`/`distrobox`)
- `rpm-ostree install git-daemon` funzionerebbe ma richiede reboot (non pratico in gara)

### Dove trovare il codice
Documentato per intero in `/app/output/DOCS/TODO.md` con snippet pronti da reintegrare
e lista di alternative da valutare (git bundle, toolbox wrapper, http-backend).
